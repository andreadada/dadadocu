# DadaProgressions beta-26.6

Beta 26.6 is a smaller update focused on cleaning up a few things before moving on to bigger features.

There are no required config changes if you're already using beta-26.5.

<!-- truncate -->

## Crafting progress fix

Shift-click crafting now takes the player's available inventory space into account.

Previously, if you shift-clicked a recipe with enough materials but almost no free inventory space, the plugin could count more crafted items than the player actually received. This is now limited to what can really fit in the inventory.

Normal crafting behaviour is unchanged.

## Better old-version checks

The build now includes an extra compatibility check against the Spigot 1.8.8 API.

This doesn't change anything you need to configure, but it helps catch accidental use of newer-only Bukkit methods before a build is released.

## General cleanup

A few temporary files used while the beta-26.5 storage update was being developed have been removed, and release branches now go through the normal build checks too.

## Updating

If you're coming from beta-26.5:

1. run `/dp admin backup`;
2. stop the server;
3. replace the old jar with `DadaProgressions-beta-26.6.jar`;
4. start the server;
5. run `/dp admin validate`;
6. check a few goals and one reward claim before opening the server again.

Your existing goals, progress and storage files do not need to be converted for this update.
