# DadaProgressions beta-26.6

This is a smaller update focused on cleaning up a few things and making the current beta more reliable before moving on to bigger features.

The main fix is related to shift-click crafting. DadaProgressions now takes the space actually available in the player's inventory into account, so crafting goals should no longer count items that the player could not really receive because the inventory was almost full.

<!-- truncate -->

It also includes a few general improvements:

- Better shift-click crafting progress tracking.
- Extra compatibility checks for older Minecraft server versions.
- More release checks before a build is considered ready.
- Cleanup of temporary files that were only needed during the beta-26.5 storage update.
- General stability and maintenance improvements.

If you're updating from beta-26.5, you don't need to change your current configuration or convert your existing data.

As usual, I still recommend making a backup of `plugins/DadaProgressions/` before updating a live server.

DadaProgressions is still in beta, so if you notice anything unusual after updating, please report it. Feedback from real servers is especially useful while the plugin is still being improved.
