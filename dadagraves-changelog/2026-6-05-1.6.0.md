### Newest version compatibility

- Added support up to Minecraft 26.1.2.

### Commands

- Added `/graves graveyard set`.
- Added `/graves graveyard tp`.
- Added tab completion for the new graveyard commands.

### Graveyard

- Added the graveyard system.
- When a player respawns after dying, they are teleported to the graveyard if one has been configured.
- If no graveyard is configured, DadaGraves does not change the player's respawn location.

### Holograms

- Improved hologram cleanup when a gravestone is removed.
- Removed hologram leftovers more reliably when a grave expires or is deleted.
