Commands and Permissions

Main command:

/dp

Alias:

/dadaprogression

/achievements opens the GUI by default. You can change GUI-only aliases in config.yml.

Player commands​

CommandNotes
/dpOpens the main GUI.
/dp guiSame as /dp.
/dp questsOpens daily goals.
/dp achievementsOpens lifetime goals.
/dp claim <goalId> [tierPercent]Claims all unlocked tiers for a goal, or one selected tier.
/dp claimallClaims all available tiers across all goals.
/dp progress [goalId]Shows progress for one goal, or all goals.
/dp top <goalId> [page]Shows the text leaderboard.
/dp lb <goalId> [page]Alias for /dp top.
/dp leaderboard <goalId> [page]Alias for /dp top.

GUI aliases​

commands:
  gui-open-aliases:
    - "achievements"
    - "quests"

Aliases must be one word commands. Do not include spaces.

Admin commands​

CommandNotes
/dp admin editorOpens the visual goal editor. Invalid edits are rolled back automatically.
/dp admin listLists loaded goals.
/dp admin info <goalId>Shows target, scope, period, type, and tiers.
/dp admin debug <goalId> <onlinePlayer> [timeoutSeconds]One-shot trace of the next relevant event. Shows filter checks, winning point rule, base/final points, prerequisites, and cooldown. Timeout: 5–600 seconds, default 60.
/dp admin debug cancel <onlinePlayer>Cancels a pending debug trace for that player.
/dp admin reloadSafely reloads config, GUI, goals, and storage; invalid goal files leave the previous registry active.
/dp admin validateRe-reads goal files without applying them, then checks storage health.
/dp admin backupCreates a manual data backup.
/dp admin repairRecreates missing directories and rebuilds derived indexes.
/dp admin rebuildindexesRebuilds player-goal leaderboard indexes.
/dp admin addprogress <goalId> <amount> [criterionId]Adds progress to a community goal. Composite goals require a leaf criterion.
/dp admin addprogress <goalId> <player> <amount> [criterionId]Adds player progress, or records a player contribution on a community goal.
/dp admin setprogress <goalId> <amount> [criterionId]Sets community progress.
/dp admin setprogress <goalId> <player> <amount> [criterionId]Sets player progress.
/dp admin trigger <goalId> <player> <amount> [criterionId]Adds progress from an external trigger.
/dp admin reset <goalId>Resets one goal.
/dp admin resetperiod <daily|weekly|monthly>Resets the current period for matching goals.
/dp admin resetplayer <player> <goalId>Resets one player's progress and claims.
/dp admin resetclaims <goalId> [player]Resets tier claims.
/dp admin resetcontributions <goalId> [player]Resets contribution data.

Visual goal editor​

The editor can:

  • rename, duplicate, enable, disable, or safely delete goals;
  • change scope and period;
  • add or remove composite criteria and edit their type and exact target;
  • add, edit, or remove global and per-criterion filters;
  • edit point base, rounding, ordered SET/MULTIPLY rules, values, conditions and per-rule ALL/ANY mode;
  • switch the root operator between AND and OR;
  • add or remove achievement prerequisites and switch ALL/ANY mode.

Targets use a numeric keypad. Materials, entities, worlds, game modes, damage causes, attribution values, and prerequisite goals use paginated selectors. Private chat remains available for permissions, commands, custom values, and accessibility; use none to clear a list and cancel to abort.

Changes are saved atomically. The plugin validates and reloads the complete goal set after every write, restoring both the original file and runtime registry if validation fails.

The filter editor also exposes ALL/ANY mode. ALL requires every filter in that context; ANY accepts the event when at least one matches.

Examples​

Claim rewards for one goal:

/dp claim community_daily_mining

Claim a specific tier:

/dp claim community_daily_mining 50

Trigger a vote goal:

dp admin trigger player_daily_vote %player% 1

Add progress manually:

/dp admin addprogress community_daily_mining 250
/dp admin addprogress player_daily_hunter Steve 5
