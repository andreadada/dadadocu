Display and rewards

Display keys​

display:
  name: "<green>Daily Hunter"
  material: "IRON_SWORD"
  lore:
    - "<gray>Defeat 30 mobs today."
    - "<gray>Progress: <white>%progress%</white>/<white>%target%</white>"
KeyTypeDefaultPurpose
display.nameStringGoal IDName shown in menus and messages using %goal_name%. Supports the configured text formatting.
display.materialStringCHESTBukkit material used for the goal icon. Use a name available on the target server.
display.loreString listEmptyShort objective text shown on goal entries. Placeholders are resolved for the viewer.

Keep lore focused on the objective. Technical progress, tiers, prerequisites, and completion state are already available in the detail menu.

Reward tiers​

Tier keys are positive percentage integers. Both 50 and 50% are accepted.

tiers:
  25:
    name: "<green>Starter"
    reward-commands:
      - "eco give %player% 100"
  50:
    name: "<yellow>Halfway"
    reward-commands:
      - "crate key give %player% common 1"
  100:
    name: "<gold>Complete"
    reward-commands:
      - "lp user %player% permission set server.goal.complete true"
KeyTypeDefaultPurpose
tiers.<percent>Section—Defines one milestone. Percent must be greater than zero. Composite goals are limited to 100%.
tiers.<percent>.nameString<percent>% RewardLabel shown in the reward UI and messages.
tiers.<percent>.reward-commandsString listEmptyCommands executed by the console when this tier is claimed. Do not include a leading /.

Commands are not run when a tier merely becomes available. They run when the tier is claimed, unless claim-mode: AUTO claims it automatically.

Claim mode​

ValueBehavior
MANUALPlayers claim through the GUI, /dp claim, or /dp claimall. This is the default.
AUTONewly unlocked tiers are claimed automatically for the actor when the goal completes. Previously unlocked or offline claims can still require manual action.
claim-mode: MANUAL

Legacy completion reward​

reward-commands:
  - "say %player% completed %goal_name%!"

When no tiers section exists, top-level reward-commands becomes a 100% completion tier. Prefer explicit tiers for new configurations.

Completion broadcast​

completion-broadcast: "<gold>%player%</gold> completed <white>%goal_name%</white>!"

This message is sent when the goal changes from incomplete to complete. Notification event settings can provide additional completion messages, so check both sections if players see duplicates.

Reset timezone​

reset-settings:
  timezone: "Europe/Rome"

Use a valid IANA timezone. It changes period boundaries for this goal only. If omitted, settings.timezone from config.yml is used.

Useful placeholders​

  • %player% and %player_uuid%
  • %goal_id% and %goal_name%
  • %progress%, %player_progress%, %community_progress%
  • %target%, %percent%, %remaining%
  • %contribution% and %rank%
  • %tier% and %tier_name%
  • %next_reset%
  • %missing_prerequisites%

See Placeholders for the complete public and internal placeholder reference.
