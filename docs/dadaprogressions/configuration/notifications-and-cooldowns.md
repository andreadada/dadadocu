# Notifications and cooldowns

This page is kept as a compatibility entry point for older documentation links.

The two systems are configured separately:

- [Notifications](notifications.md) control chat, actionbar, title, bossbar, queueing, compaction, and message frequency.
- [Cooldowns and periods](cooldowns-and-periods.md) control reset windows and how often matching events may award progress.

If a goal is progressing too often, change its cooldown or filters. If it progresses correctly but sends too many messages, change notification settings instead.
