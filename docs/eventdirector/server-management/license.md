# License and premium version

Some EventDirector builds may include license information or premium features.

## License command

```mcfunction
/eventdirector license
```

or:

```mcfunction
/ed license
```

## What to check

The license section may show:

- license status;
- build type;
- plugin version;
- support information;
- possible limitations.

## Premium features

If your build includes premium features, make sure to:

- use a valid plugin copy;
- read the release changelog;
- avoid sharing private files;
- keep test and production servers separate;
- update the documentation when premium behavior changes.

:::info
If the license command is a placeholder in your build, it may only show basic information or may not yet be connected to a real verification system.
:::
