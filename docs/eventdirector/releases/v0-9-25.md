# Release 0.9.25 RC

This page summarizes the documented features for EventDirector v0.9.25 RC.

## Release focus

This release is focused on making EventDirector safer, better documented, and more ready for serious testing.

## Main features

- Setup wizard for first configuration.
- Backup and restore tools.
- Safe mode.
- Update checker.
- Version diagnostic commands.
- License/premium placeholder support.
- Premium documentation can be separated if needed.
- Better resource quality control.
- Internal testing around backups, migrations, configurations, and policies.

## Notes for administrators

Before updating:

1. create a backup;
2. read the changelog;
3. install the new build;
4. start the server;
5. check the console;
6. test setup, backup, and GUI;
7. test at least one event.

## Stability note

Because this is an RC build, it is recommended to test it in a safe environment before using it on a live production server.

## Post-update checklist

- `/eventdirector version` responds correctly.
- Setup wizard is accessible.
- Admin GUI is accessible.
- Manual backup works.
- Restore has been tested in a safe environment.
- Safe mode can be enabled and disabled.
- Main events load without errors.
